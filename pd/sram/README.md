# SRAM macro models

`sky130_sram_1kbyte_1rw1r_32x256_8.{lib,lef,v}` are the OpenRAM-generated
SkyWater 130 nm macro (32 bits x 256 words, one RW port + one R port) from
https://github.com/VLSIDA/sky130_sram_macros (BSD-3-Clause). Only a TT
(1.8 V, 25 C) liberty is published, so STA uses TT macro timing at every corner.

`npu_sram` (USE_MACRO = 1) maps a 128-bit x 128-word bank onto four of these
side by side; only 128 of each macro's 256 words are used. The `_TT_as_<corner>.lib`
copies are generated by `scripts/run_synth.py` (OpenSTA needs a distinct library
name per corner) and are not checked in.
